# About

## 项目简介

**Robot Knowledge** 是一个面向机器人开发实践的知识库，聚焦于可复用、可落地的工程经验沉淀。

内容覆盖：

- Navigation（Nav2）
- Perception（RGBD / ESDF / 地面拟合）
- ROS2 系统工程
- Reinforcement 学习笔记

## 目标

这个项目希望解决两个问题：

1. 把分散的实验记录整理成结构化文档
2. 把常见问题和踩坑经验变成可检索的知识资产
