    Robot Knowledge¶

    机器人知识库，整理导航、感知、系统工程与强化学习相关的实践笔记与配置经验。

    你可以在这里找到什么¶

    • Navigation / Nav2: 架构、代价地图、全局与局部规划器相关笔记
    • Perception: RGBD 深度处理、ESDF 集成、地面拟合等内容
    • System / ROS2: 容器化部署、TF 使用经验与常见问题
    • Reinforcement: 学习路径与入门资料整理

    快速开始¶

    # 本地预览（推荐开发时使用）
mkdocs serve

# 生成静态站点
mkdocs build

    本地预览地址（默认）：

    http://127.0.0.1:8000/robot-knowledge/

    阅读建议¶

    如果你是第一次访问，建议按下面顺序阅读：

    1. Navigation / Nav2 架构
    2. Perception 中的 RGBD 与 ESDF
    3. ROS2 系统实践（Container 与 TF）
    4. 最后再看 Reinforcement 的学习笔记
