    Linefit Ground Segmentation (线拟合地面分割)¶

    linefit_ground_segmentation 是一种用于 3D 激光雷达点云（如 Velodyne, Ouster 等）的快速、鲁棒的地面分割算法。它在自动驾驶和移动机器人的感知模块中非常常见，主要用于从杂乱的三维点云中剥离出地面点，从而将剩下的非地面点（障碍物）送入后续的聚类、追踪或构建代价地图（Costmap）模块。

    为什么需要地面分割？¶

    1. 减少计算量：地面点通常占据了 3D 激光雷达点云的极大比例（往往超过 50%）。尽早剔除它们，可以大幅降低后续障碍物检测算法的压力。
    2. 避免虚假障碍物：如果直接把原始点云投影到 2D 平面，由于地面的起伏和雷达的安装倾角，地面点很容易被误认为墙壁或障碍物，导致机器人“鬼影刹车”或无法前行。

    算法核心原理¶

    传统的平面拟合（如 RANSAC 平面拟合）假设地面是一个绝对的水平面，这在平坦的室内有效，但在有坡度、坑洼的室外场景中很容易失效。

    Linefit 算法的巧妙之处在于，它把 3D 空间的问题降维成了多个 2D 的线拟合问题。其核心流程分为以下几个步骤：

    1. 极坐标系网格化 (Binning)¶

    以雷达中心为原点，将 360 度的点云划分成极坐标网格： - 方位角 (Azimuth/Angle)：将 360 度划分为多个扇区（Segments）。 - 径向距离 (Radius)：在每个扇区内，根据距离雷达的远近，划分为多个区间（Bins）。

    这样，整个 3D 空间就被切分成了像切蛋糕一样的网格。

    2. 提取局部最低点¶

    在每个细分的网格 (Bin) 中，找到 Z 轴高度最低的点。因为在大多数情况下，每个小网格的最低点极大概率就是地面点。 通过这一步，点云数据量被大幅压缩，每个扇区变成了一条由“距离-高度” (Distance-Z) 组成的 2D 散点图。

    3. 迭代线拟合 (Iterative Line Fitting)¶

    针对每个扇区（Segment），算法从距离雷达最近的 Bin 开始，向外进行 2D 直线拟合： - 取相邻的最低点尝试拟合一条线段。 - 如果这条线段的斜率 (Slope) 和 拟合误差 (Fit Error) 在设定的阈值范围内，就认为这段线代表了该区域的真实地面轮廓。 - 这个过程是分段、迭代进行的，因此即使地面有上下坡度，算法也能自适应地跟踪地面的起伏。

    4. 判定地面点¶

    在计算出每个扇区的地面高度基准线后，算法会遍历该扇区内的所有原始 3D 点。 - 如果某个点的高度到基准线的垂直距离小于设定的阈值（max_dist_to_line），则将其标记为地面点。 - 否则，标记为非地面点（障碍物）。

    核心参数解析¶

    要让该算法在你的机器人上表现良好，通常需要调节以下关键参数：

    • sensor_height: 激光雷达的安装高度（距离地面的 Z 值）。这是算法寻找起点的基准。
    • n_bins / n_segments: 径向和角向的划分数量。值越大，对复杂地形的分辨率越高，但计算量也越大。
    • max_fit_error: 线拟合允许的最大误差。如果地面比较粗糙（草地、碎石路），需要调大该值；如果在平坦的水泥地，可以调小以提高精度。
    • max_slope / max_error_to_line: 地面允许的最大坡度。调大可以适应更陡的坡道，但可能把斜面的障碍物（如斜坡墙面）误认为地面。
    • min_range / max_range: 需要处理的点云最小和最大距离。剔除打在车体上的噪点，或舍弃过远的稀疏点。

    优缺点总结¶

    优点： - 速度极快：得益于降维和极坐标分块，计算效率远高于 3D 空间内的 RANSAC 或法向量聚类，轻松满足 10Hz/20Hz 的实时处理需求。 - 适应起伏地形：分段线拟合的设计使其能够完美贴合上下坡地形。

    缺点： - 对悬崖/台阶不敏感：如果环境存在垂直的台阶或坑洞，算法可能会在边缘产生错误的拟合。 - 参数敏感：在极端复杂的非结构化地形中，一套固定的参数可能无法同时兼顾所有情况。
